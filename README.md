# Wona Design Studio — Website

A responsive, modern website for **Wona Design Studio**, a strategic creative agency that builds authentic, memorable brands for ambitious businesses and creatives.

> *Crafting Brands, Inspiring Connections.*

---

## Overview

This project is a marketing and portfolio website for Wona Design Studio. It sits at the meeting point of creativity and strategy — showcasing services, selected work, and an interactive demo brand system.

**Short descriptor:** Where strategy and creativity meet to build brands that connect, inspire, and perform.

---

## Brand Voice

All copy should be **warm, clear, encouraging, creative, visionary, approachable, and professional**. Emphasize collaboration, uniqueness, strategy, and measurable results.

---

## Pages

| Page | Purpose |
|------|---------|
| **Home** | Hero, positioning, services snapshot, demo project, projects, process, testimonials, final CTA |
| **About** | Brand story, beliefs, values, approach |
| **Services** | Strategy, identity, messaging, systems, digital — with outcomes and deliverables |
| **Projects** | Filterable portfolio grid linking to case studies |
| **Demo Project** | Interactive sample brand system demonstrating Wona's process |
| **Contact** | Welcoming contact form and details |

---

## Key Sections

### Demo Project
An interactive, highlighted section that lets visitors explore a sample brand system — including palette swatches, type specimens, before/after toggles, and mockups. Positioned as a guided preview of Wona's approach.

### Projects
A filterable portfolio grid (6–9 placeholder projects) with category tags, one-line results, and links to full case studies (Challenge, Approach, Solution, Results, Gallery).

---

## Visual Direction

- Clean, editorial, warm-professional feel
- Generous whitespace, strong typography, refined grid
- Palette: off-white/cream, charcoal text, one muted accent (terracotta, sage, or warm ochre)
- Serif/display headlines + clean sans-serif body
- Authentic imagery: mockups, typography details, packaging — no generic stock photos

---

## Tech Requirements

- Fully responsive (mobile, tablet, desktop)
- Fast-loading, SEO-friendly, accessible
- CMS-ready for Projects and Demo Project content
- Subtle animations only (fade-ins, hover states, smooth transitions)
- Clear navigation and strong CTAs throughout

---

## Getting Started

```bash
# Clone the repository
